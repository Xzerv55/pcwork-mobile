# PCWork Mobile v74 – инсталиране и проверка

1. Разархивирайте изходния проект.
2. В Flutter среда изпълнете `flutter pub get`.
3. Изпълнете `flutter analyze`.
4. Проверете конфигурацията Firebase и Android signing според съществуващите инструкции.
5. Компилирайте APK само след проверка на `google-services.json` и signing ключа.

Версията на source проекта е `0.74.0+74`. Този архив съдържа source code, не APK.
