# PCWork Mobile v60 – Инсталиране

## 1. WordPress плъгин
1. Направете резервно копие на сайта.
2. В WordPress → Разширения качете `PCWork_Mobile_WordPress_Plugin_v4.2.0.zip`.
3. Обновете/заменете предишната версия на PCWork Mobile – Complete System и активирайте плъгина.
4. При първо зареждане плъгинът автоматично ще създаде таблицата `wp_pcwork_repair_worklog` (с реалния префикс на базата).
5. Проверете `/wp-json/pcwork/v1/health` и потвърдете версия 4.2.0.

## 2. GitHub мобилно приложение
1. Разархивирайте `PCWork_Mobile_App_v60.zip`.
2. Качете съдържанието на `PCWork_Mobile_App_v60/` в `Xzerv55/pcwork-mobile`, като замените съответните файлове.
3. Запазете вашия реален `android/app/google-services.json` – архивът съдържа само примерен файл.
4. Стартирайте GitHub Actions → Build installable Android APKs.
5. Изтеглете APK само след успешно завършване на workflow.

## 3. Нов сервизен дневник
Отворете ремонт → „Сервизен дневник · дейности, части и плащания“.
- Служителите могат да добавят диагностика, извършена работа, резервни части, плащания и гаранция.
- Отметката „Видимо за клиента“ определя кои записи клиентът може да вижда.
- Клиентът има само права за преглед.
- Балансът се изчислява като стойност на диагностика/работа/части минус записаните плащания.

Важно: Не въвеждайте плащане, преди реално да е получено. Въведените записи са сервизна отчетност, а не автоматично обработване на картово плащане.
