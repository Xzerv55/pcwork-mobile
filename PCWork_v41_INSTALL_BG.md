# Инсталиране на PCWork Mobile v42

1. Направете commit/push на съдържанието на архива в GitHub `Xzerv55/pcwork-mobile`.
2. Запазете `.github/workflows` и вашия `android/app/google-services.json`. Архивът съдържа само примерен Firebase config.
3. Стартирайте GitHub Actions → PCWork Android APK. Изтеглете APK artifact след успешен workflow.
4. В WordPress обновете единния плъгин PCWork Mobile – Complete System до 3.1.0. Не инсталирайте втори екземпляр паралелно.
5. Отворете приложението и тествайте „Начало → Сервизни обекти“, след това „Записване → Избери сервизен обект“.

Директорията включва 9 позиции: София – Люлин 5, София – Люлин 2, София – Симеоновско шосе, София – Индустриална 11, Варна – Център, Бургас – Център, Пловдив – Велико Търново, Пловдив – Център и Шумен – Център. Петте предстоящи локации са само за преглед и не могат да се изберат за записване.

При вход, ако грешката продължи, изпратете точния stack trace от Android logcat; тази корекция премахва известните null assertions в екрана за вход и критичния екран с детайли на ремонта, но не замества проверката на реалния WordPress отговор.
