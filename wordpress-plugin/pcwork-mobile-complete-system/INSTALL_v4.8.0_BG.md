# Инсталиране – PCWork Mobile WordPress Plugin v4.8.0

1. Направете резервно копие на WordPress файловете и базата данни.
2. В WordPress → Plugins обновете съществуващия **PCWork Mobile – Complete System** с този ZIP. Не инсталирайте второ копие със същия плъгин.
3. След обновяване отворете **PCWork Mobile → Клиенти**. Ограничението за онлайн заявки е 10 на профил и 1000 от една мрежа за 24 часа; новите броячи премахват блокирането от стария по-нисък лимит.
4. В таба **Реклами и кампании** създавайте/планирайте кампании и изтривайте ненужни кампании. Изтриването отменя чакащото планирано изпращане; вече доставено push известие не може да бъде оттеглено.
5. В таба **Поръчки** преглеждайте последните 100 WooCommerce поръчки. Бутонът „Изтрий“ ги премахва окончателно чрез WooCommerce CRUD (включително HPOS).
6. Съществуващите интеграции, API маршрути, ремонти, клиенти, FCM устройства, настройки и маркетингово съгласие се запазват.

Изтриването на поръчка или клиент е необратимо. Използвайте го само след проверка и потвърждение.
