# PCWork Mobile WordPress Plugin v4.7.0

- Надгражда директно v4.6.0 и запазва всички нейни функции за клиенти, управление на достъпа, ремонти, редактиране и изтриване.
- Google Sheets синхронизацията се поставя във фонова WP-Cron задача, за да не задържа REST заявката за нов ремонт.
- Push известията за нови клиентски заявки, промени по ремонта и нови WooCommerce поръчки се обработват във фонова задача.
- Добавени са служебни push известия за нова заявка за ремонт и нова поръчка; те не зависят от маркетинговото съгласие.
- Chatway получава защитено Visitor Verification и име, имейл и телефон след инициализация на widget-а. Тайният ключ остава само в WordPress.
- Запазени са диагностичният `/push/status` endpoint, маркетинговото съгласие и сървърната проверка за описание на проблем с поне 15 смислени символа.
