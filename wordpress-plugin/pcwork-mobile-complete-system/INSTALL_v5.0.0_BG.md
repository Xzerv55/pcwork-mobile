# Инсталиране – PCWork Mobile WordPress Plugin v5.0.0

1. Направете резервно копие на WordPress файловете и базата данни.
2. В WordPress → Plugins обновете съществуващия **PCWork Mobile – Complete System** с този ZIP. Не инсталирайте второ копие със същия плъгин.
3. При първо зареждане плъгинът добавя таблицата `wp_pcwork_chat_messages` чрез `dbDelta`. Не се изтриват съществуващи таблици, ремонти, клиенти или поръчки.
4. Отворете **PCWork Mobile → Чат**, за да управлявате разговорите. Клиентските съобщения и снимки се свързват с WordPress профила; приложението проверява за нови съобщения през 10 секунди само докато чатът е отворен.
5. Push известията за нови чат съобщения използват съществуващата Firebase конфигурация, ако Push е активиран.
6. Старите Chatway REST маршрути, widget и настройки са премахнати. Само старите Chatway ключове се изчистват от опцията за интеграции; всички останали настройки се запазват.
7. За Google Sheets качете актуализирания `Code.gs` версия 2.7.0 в съществуващия Apps Script проект и го внедрете като нова версия. Новият тест проверява реално записване в отделен временен лист, който се изтрива след проверката.

Преди production обновяване направете резервно копие и тествайте първо на staging среда.
