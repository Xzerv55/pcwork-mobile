# PCWork Mobile v48 – корекции по обратната връзка

## Приложение 0.48.0+48
- Долното меню е с намалена височина.
- Настройките вече работят като чернова: промени се записват само с „Запази настройките“. При избор на друг основен таб панелът се затваря и незаписаните промени се изоставят.
- Бутонът за FCM token затваря настройките, инициализира Firebase с диагностични съобщения, включва auto-init, и прави повторни опити при липса на token.
- Chaty и Chatway са обединени в един екран „Чат“ с вътрешен превключвател „Контактни бутони“ / „Чат на живо“. Зарежда се само избраният канал.

## WordPress плъгин 3.4.0
- Добавена е диагностика за wp_mail_failed при изпращане на OTP, без записване на самия код.
- Добавен е административен тестов имейл до WordPress admin email в PCWork Mobile → Интеграции.
- При неуспешно wp_mail приложението получава по-конкретно съобщение за SMTP диагностика.
- OTP продължава да използва wp_mail; успешното връщане от WordPress не гарантира доставяне в Inbox. За реална доставка е необходим работещ SMTP и правилни SPF/DKIM записи.

## Ограничения на проверката
PHP синтаксисът и ZIP целостта се проверяват при пакетиране. Flutter/Dart SDK не е наличен в тази среда, затова `flutter analyze`, Android build и iOS build трябва да се изпълнят в GitHub Actions. Не е извършен live тест на SMTP, Firebase, Chaty или Chatway на pcwork-bg.com.
