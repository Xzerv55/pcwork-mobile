# PCWork Mobile v76 – изходен код

Версия: **0.76.0+76**. Съвместим плъгин: **PCWork WordPress Plugin v5.7.0**.

Качете съдържанието на архива в GitHub repository и стартирайте workflow `PCWork Android APK`. За подписване са необходими съществуващите GitHub Actions secrets и оригиналният release keystore. Не заменяйте Firebase конфигурацията или ключа за подписване.

APK не е включен в ZIP архива. Артефактът от GitHub Actions е `pcwork-android-v76-apks`.
