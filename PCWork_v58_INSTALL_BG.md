# PCWork Mobile v58 — инструкции

## Android / GitHub Actions
1. Качете съдържанието на проекта в съществуващото хранилище `Xzerv55/pcwork-mobile`.
2. Запазете папката `.github/workflows` и съществуващия workflow `PCWork Android APK`.
3. Проверете дали `android/app/google-services.json` е наличен за Firebase проекта.
4. Стартирайте GitHub Actions workflow `PCWork Android APK`, когато сте готови за компилация.

## WordPress
1. Направете резервно копие на сайта и базата данни.
2. Обновете съществуващия плъгин `PCWork Mobile – Complete System` с архива `PCWork_Mobile_WordPress_Plugin_v4.0.0.zip`. Не инсталирайте втори екземпляр.
3. Проверете WooCommerce да е активен и интеграцията да е разрешена в административните настройки на PCWork Mobile.
4. След обновяването тествайте вход, редакция на клиентски профил, запазване на billing/shipping адреси и тестова поръчка.

## Важно
- Имейлът за регистрация е непроменяем от мобилния профил и checkout.
- Настройките се запазват автоматично.
- Режимите „Преглед като служител/клиент“ са само визуални; WordPress продължава да проверява реалните права.
- Google Apps Script остава на съществуващата версия v2.6.0; не е променян в тази версия.
- В този пакет няма APK. Компилацията се изпълнява от GitHub Actions.
