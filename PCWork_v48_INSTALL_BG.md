# PCWork Mobile v48 – инструкции

1. Направи backup на WordPress файловете и базата данни.
2. Качи съдържанието на този архив в съществуващото GitHub repository `Xzerv55/pcwork-mobile`, като запазиш `.github/workflows` и реалния `android/app/google-services.json`.
3. Запази Firebase Actions Secrets. Не качвай Service Account JSON или private keys в GitHub.
4. Стартирай GitHub Actions → PCWork Android APK. Изтегли `pcwork-android-v48-apks`.
5. Обнови съществуващия единен WordPress плъгин до 3.4.0. Не активирай втори копие и не изтривай настройките.
6. В WordPress → PCWork Mobile → Интеграции натисни „Изпрати тестов имейл“. Тестът отива до административния имейл в Settings → General. Провери Inbox и Spam. Ако не пристигне, конфигурирай SMTP с потвърден адрес и SPF/DKIM записи.
7. Тествай регистрация с нов имейл и потвърди, че OTP пристига.
8. В приложението отвори Настройки → Покажи / копирай FCM token. Ако не работи, запиши пълното диагностично съобщение.
9. В раздел „Чат“ провери и двата вътрешни раздела: „Контактни бутони“ и „Чат на живо“.

## Важно
- Незапазените настройки се изоставят при смяна на основния таб.
- Тестовият имейл потвърждава, че WordPress mail transport приема писмото, но не може сам да гарантира inbox delivery.
- Flutter анализ/компилация и реалните интеграционни тестове трябва да се потвърдят след GitHub Actions и инсталация.
