# Инсталация – PCWork Mobile v68

1. Разархивирайте проекта и изпълнете `flutter pub get`.
2. Инсталирайте обединения WordPress плъгин v5.0.0 от отделния ZIP архив.
3. След активиране плъгинът създава допълнителната таблица `wp_pcwork_chat_messages` чрез `dbDelta`. Съществуващите таблици и записи не се изтриват.
4. В WordPress администрацията отворете **PCWork Mobile → Чат** за разговорите с клиенти.
5. За push известията остават активни съществуващите Firebase настройки. При ново чат съобщение се изпраща известие до съответния клиент или служебните профили, ако push е включен.
6. Google Apps Script файлът `google-apps-script/Code.gs` е обновен до версия 2.7.0. Качи го в съществуващия Apps Script проект и направи ново внедряване (Deploy → Manage deployments → Edit → New version), за да работи реалната проверка за запис в таблицата.
7. Старите Chatway настройки се премахват автоматично от опцията за интеграции при зареждане на администрацията. Старите Chatway кодове и REST маршрути вече не се използват.

Преди качване на production направи резервно копие на базата и файловете. APK не е включен в този изходен архив.
