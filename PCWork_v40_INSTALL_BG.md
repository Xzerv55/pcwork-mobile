# PCWork Mobile v40 – инсталиране

## 1. Резервно копие
Направете backup на WordPress файловете и базата данни. Запазете текущия GitHub branch. Не деинсталирайте стария PCWork плъгин.

## 2. WordPress плъгин
1. WordPress → Plugins → Installed Plugins.
2. Обновете съществуващия **PCWork Mobile – Complete System** с `PCWork_Mobile_WordPress_Plugin_v3.0.0.zip`.
3. Не инсталирайте втори PCWork Mobile плъгин.
4. Отворете **PCWork Mobile → Интеграции** и проверете, че текущите Firebase, Google Sheets, Bookly, WooCommerce, Chatway и Chaty настройки са запазени.
5. Проверете Push настройките: Push е включен, Firebase Project ID е правилен и Service Account JSON е записан само в WordPress.

## 3. Съгласие за рекламни известия
В WordPress → Users → избран клиент → PCWork – маркетингови известия. Включвайте отметката само след изрично съгласие на клиента. Без отметка клиентът няма да получава рекламни кампании. Сервизните известия за ремонти остават отделни.

## 4. Изпращане на кампания
1. Отворете **PCWork Mobile → Маркетинг и Push**.
2. Въведете заглавие и текст (до 80/240 знака).
3. По желание добавете HTTPS линк и HTTPS изображение.
4. Изберете всички абонирани клиенти или само абонираните клиенти с роля `customer`.
5. Изпратете веднага или изберете планиране и дата/час.
6. Проверете историята и броя изпратени/неуспешни устройства.

Планираните кампании изискват WP-Cron. За надеждно изпълнение в точен час настройте системен cron за `wp-cron.php`.

## 5. Android приложение
1. Качете съдържанието на `PCWork_Mobile_App_v40.zip` в `Xzerv55/pcwork-mobile`, като запазите `.github/workflows`.
2. Уверете се, че `android/app/google-services.json` остава наличен в частното GitHub хранилище или се генерира от вашия защитен workflow. Не го заменяйте с `.example`.
3. GitHub → Actions → **PCWork Android APK**.
4. Изчакайте `Analyze Dart code`, Debug APK и Release APK.
5. Изтеглете артефакта `pcwork-android-v40-apks`.

## 6. Проверка
- Инсталирайте APK и влезте с тестов клиент.
- Проверете разрешението за известия и регистрацията на устройството.
- В WordPress включете маркетингово съгласие за тестовия клиент и изпратете тестова кампания.
- Проверете известието при затворено приложение и при отворено приложение.
- Проверете, че клиент без маркетингово съгласие не получава рекламната кампания.
