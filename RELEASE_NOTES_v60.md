# PCWork Mobile v60

## Етап 2 – Управление на ремонтите

- Добавен е сервизен дневник към всеки ремонт.
- Служителите с достъп до съответния сервизен обект могат да добавят диагностика, извършена работа, резервни части, плащания и гаранционни записи.
- Всеки запис съдържа описание, количество/единична цена/сума, дата на гаранция и настройка дали е видим за клиента.
- Добавени са обобщения за стойност на дейностите и частите, платена сума и оставащ баланс.
- Клиентите виждат само записите, маркирани като видими за тях; нямат права за редакция.
- Използва се WordPress като основен източник на данни.
- Запазени са съществуващите потоци за приемане, статуси, история, разпределяне към техник, снимки, подписи, документи и push известия.
- Добавени са REST endpoints за сервизния дневник и автоматична DB миграция.
- GitHub Actions: upload-artifact е обновен до v6 (Node.js 24); checkout и setup-java остават на v5.

## Проверки

- PHP синтаксисът на WordPress плъгина е проверен.
- ZIP архивите са проверени за цялост.
- Flutter SDK не е наличен в средата за тази задача; `flutter analyze` и реална Android компилация трябва да се изпълнят в GitHub Actions.
