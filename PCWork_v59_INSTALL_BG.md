# PCWork Mobile v59 – инструкции за обновяване

## 1. GitHub приложение
1. Направи резервно копие на текущото хранилище.
2. Разархивирай `PCWork_Mobile_App_v59.zip`.
3. Качи съдържанието на папката `PCWork_Mobile_App_v59` в основната папка на GitHub хранилището и замени старите файлове. Запази реалния `android/app/google-services.json` в хранилището; примерният файл не го замества.
4. Провери, че `.github/workflows/` съдържа двата обновени workflow файла.
5. Стартирай GitHub Actions ръчно.

## 2. WordPress плъгин – задължително за HTTP 404
1. В WordPress направи резервно копие.
2. Деактивирай старата версия на `PCWork Mobile – Complete System`.
3. Качи и активирай `PCWork_Mobile_WordPress_Plugin_v4.1.0.zip`.
4. В приложението влез отново в профила си и провери „Промоции и новини“.

## 3. Chatway
За автоматично разпознаване на регистриран клиент трябва да е включено Chatway Visitor Verification и да е въведен Verification Security Key в настройките на PCWork. Приложението не получава и не съхранява този ключ. В Visitor Verification се използва избраният идентификатор (WordPress ID или email). Името, имейлът и телефонът се подават от WordPress профила.

## 4. Проверки
- `flutter analyze`
- Android APK build през GitHub Actions
- Вход и редактиране на профил
- Проверка на маркетинговото съгласие (вкл. включване и изключване)
- Chatway в светла и тъмна тема
- Продуктова снимка в магазин и количка

Този архив не съдържа APK и не включва реален `google-services.json`.
