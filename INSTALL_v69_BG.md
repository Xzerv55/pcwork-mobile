# Инсталация и подготовка – PCWork Mobile v70

1. Използвайте този архив като изходен код на приложението.
2. Инсталирайте отделния обединен WordPress плъгин v5.1.0.
3. Изпълнете `flutter clean`, `flutter pub get` и `flutter analyze` в проекта.
4. Проверете входа, навигацията, отварянето на чата, изпращането на текст и снимки и получаването на отговор от WordPress.
5. Балончето „С какво да помогнем?“ се показва при всяко ново стартиране на приложението. Натискането му отваря таба „Чат“.
6. Необходим е същият Android application ID и същият ключ за подписване при бъдещо публикуване като обновяване.

Този архив съдържа само изходен код. APK не е генериран.
