# PCWork Mobile v51 – инструкции за обновяване

1. Направи резервно копие на GitHub проекта и WordPress сайта/базата данни.
2. Обнови файловете в GitHub с тези от папка `New folder` в архива. Важно: GitHub уеб качването не изтрива автоматично файлове, които липсват в новия архив.
3. Изтрий ръчно стария екран за чат от предишната версия, ако още присъства в папка `lib/screens/` в GitHub. Версия v51 има и автоматична защитна стъпка в GitHub Actions, която изтрива остатъчни файлове от този тип преди анализа.
4. Запази реалния `android/app/google-services.json` в проекта. Той умишлено не е включен в ZIP архива. Не качвай Firebase Service Account JSON или частни ключове в GitHub.
5. Стартирай GitHub → Actions → `PCWork Android APK` → `Run workflow`.
6. След успешна компилация изтегли `pcwork-android-v51-apks`. За повечето съвременни Android телефони избери `app-arm64-v8a-release.apk`. `app-armeabi-v7a-release.apk` е за по-стари 32-битови ARM устройства, а `app-x86_64-release.apk` – за x86_64 устройства. Универсалният debug APK е само за тестове.
7. За WordPress обнови съществуващия плъгин `PCWork Mobile – Complete System` с файловете от `wordpress-plugin/pcwork-mobile-complete-system/`. Не инсталирай второ копие. Версията е `3.6.0`.
8. След обновяването провери PCWork Mobile → Интеграции и тествай входа, ремонтите, контактните бутони и Chatway.

**Важно:** Автоматичната стъпка в GitHub Actions поправя компилационния процес, дори ако старият файл остане в checkout-а, но е препоръчително да го изтриеш и от самото GitHub хранилище, за да остане чист изходният код.
