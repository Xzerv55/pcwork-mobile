# PCWork Mobile v35 – стабилност, вход и по-бърз магазин

## Промени
- Зареждане на секциите при първо отваряне вместо едновременно създаване на всички екрани при стартиране.
- Проверка на здравето на API във фонов режим, без да блокира възстановяването на сесията.
- Ремонтите се заявяват при отваряне на секцията, а не автоматично при всяко стартиране на началния екран.
- Магазинът показва по 20 продукта на заявка, с фиксирана зона за снимка, еднакво визуално представяне и ограничаване на декодирания размер на изображенията.
- Вариациите на WooCommerce се зареждат само при отваряне на конкретен променлив продукт; категориите се кешират за 5 минути.
- Чатът има ограничено време за зареждане, проверка на Chatway скрипта и възможност за отваряне във външен браузър при проблем.
- Входът приема съществуващ WordPress имейл и потребителско име; при имейл се прави и изрично съпоставяне към WordPress потребителското име, като се запазват стандартните authentication филтри.
- Ограничението за вход вече брои неуспешни опити, а не успешните влизания.
- WordPress плъгинът е обновен до 2.5.0.

## Важно за проверката
- PHP синтаксисът е проверен локално.
- Flutter SDK не е наличен в средата за тази подготовка, затова `flutter analyze` и Android/iOS компилация трябва да се потвърдят чрез GitHub Actions.
- Реален вход към WordPress и действително зареждане на Chatway не могат да се потвърдят без тест към живия сайт.
