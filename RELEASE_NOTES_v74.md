# PCWork Mobile v74

- Компактен чат интерфейс с намалени отстояния и по-добро позициониране на последното съобщение.
- Администраторски чат в приложението: списък с клиентски разговори и отговори през защитени административни REST маршрути.
- Потискане на foreground chat push диалога, когато приложението вече е отворено в таб „Чат“.
- Запазени съществуващите клиентски chat endpoints и FCM регистрация.

Flutter анализ и APK компилация не са изпълнени в средата, тъй като Flutter SDK не е наличен.
