# PCWork Mobile v35 – инсталиране

## 1. Резервно копие
1. Направи backup на WordPress сайта и базата данни.
2. Запази текущия PCWork Mobile плъгин и текущия GitHub branch.

## 2. Обнови WordPress плъгина първо
1. В WordPress отвори **Plugins → Add New Plugin → Upload Plugin**.
2. Качи `PCWork_Mobile_WordPress_Plugin_v2.5.0.zip`.
3. Обнови съществуващия **PCWork Mobile – Complete System**. Не активирай два PCWork Mobile плъгина едновременно.
4. Не изтривай настройките на плъгина. WooCommerce, Chatway, Bookly и Google Sheets настройките се пазят в WordPress options.
5. Провери, че плъгинът е активен и версията е **2.5.0**.

## 3. Обнови приложението
1. Разархивирай `PCWork_Mobile_App_v35.zip`.
2. Качи съдържанието в съществуващия GitHub repository `Xzerv55/pcwork-mobile`, като запазиш `.github/workflows`.
3. Commit changes към `main`.
4. Отвори **Actions → PCWork Android APK** и стартирай workflow, ако не се стартира автоматично.
5. Изчакай всички стъпки, включително **Analyze Dart code**, да приключат успешно.
6. Отвори завършилия run → **Artifacts** → `pcwork-android-v35-apks` и изтегли APK архива.

## 4. Тест на входа
1. Инсталирай v35.
2. Отвори **Профил → Вход**.
3. Въведи имейла на вече съществуващ WordPress потребител и неговата WordPress парола. Може да използваш и потребителското име.
4. Ако не успее, запиши точния текст и HTTP код на грешката. Не изпращай паролата.

Плъгинът v2.5.0 първо намира WordPress потребителя по имейл и след това подава неговото потребителско име към `wp_authenticate()`. Така се запазват нормалните WordPress филтри за вход, включително допълнителни security/2FA плъгини. Ограничението вече брои неуспешни опити, не успешните влизания.

## 5. Тест на магазина и чата
- Магазинът се зарежда едва при първото отваряне. Каталогът връща до 20 продукта на заявка; вариантите на променлив продукт се зареждат при отваряне на самия продукт.
- Снимките са в еднакви фиксирани зони и се декодират с ограничен размер.
- Чатът се зарежда едва при отваряне. Ако Chatway не отговори, приложението показва грешка и предлага повторен опит/външен браузър.

## Проверки и ограничения
- PHP синтаксисът на всички файлове в плъгина е проверен с PHP 8.4.
- ZIP архивите се проверяват за цялост след създаването им.
- Flutter SDK не е наличен в средата за тази подготовка: задължително потвърди `flutter analyze` и APK компилацията в GitHub Actions.
- Входът, магазинът и Chatway не са тествани live срещу WordPress акаунт/сайт от тази среда. Реалният тест след качването остава необходим.
