# PCWork Mobile v55 – инструкции

1. Разархивирай проекта и качи съдържанието на папката `PCWork_Mobile_App_v55` в GitHub repository-то, като замениш старите файлове.
2. Стартирай Android build workflow от GitHub Actions.
3. Изтегли APK от Artifacts само след успешен workflow.
4. При първо влизане след обновяването клиентът ще види обяснение за push известията и сам ще избере дали да ги разреши.
5. От Профил клиентът може отделно да включи или изключи маркетинговите съобщения.
6. Провери долната навигация на реално устройство – иконите са 29 px, зоната е 70 px и няма стандартен splash/highlight ефект при натискане.

Не е необходима промяна по Google Apps Script v2.6.0 за тази версия.
