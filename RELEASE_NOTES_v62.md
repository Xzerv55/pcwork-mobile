# PCWork Mobile v62.0 — 0.62.0+62

## Ново и променено
- Редакцията на клиентския профил вече записва автоматично след кратко изчакване; показва състояние на записа и грешки.
- Регистрационният имейл остава заключен и не се изпраща като поле за промяна.
- Името, телефонът, адресът за фактуриране и отделният адрес за доставка се записват към WordPress/WooCommerce профила.
- Бутонът за презареждане на профила е преименуван така, че ясно да показва, че зарежда сървърните данни.
- Премахнато е превключването на език от горната лента; запазена е иконата глобус.
- Добавена е опция за повторно активиране/настройване на push известията от профила. Отказът „Не сега“ не предизвиква повторен диалог при всяко стартиране.
- Добавена е проверка за нова версия чрез публичен WordPress API манифест и бутон за отваряне на HTTPS APK адреса. Инсталацията остава под контрола на Android и изисква потвърждение от потребителя.
- Подобрено е изобразяването на продуктовите снимки в количката с прозрачен фон.
- WordPress плъгинът е обновен до 4.3.0 и включва администраторски настройки за версия, versionCode, HTTPS APK адрес и бележки към версията.
- Запазени са постоянният release signing workflow, същият Android application ID и изискването за четирите GitHub Secrets.

## Запазени съществуващи модули
- Регистрация/вход с еднократен имейл код, профил и WordPress API.
- Клиентски ремонти, прием на устройство, сервизни обекти, статуси, история и документи.
- Служебни екрани за разпределяне на техници, графици, натовареност, присъствия и отпуски.
- Сервизен дневник за диагностика, труд, части, плащания и гаранции.
- Push/FCM регистрация, Chatway, WooCommerce магазин и Google Sheets синхронизация.

## Проверки и ограничения
- PHP lint и структурата на ZIP се проверяват при пакетиране.
- Flutter SDK не е наличен в тази среда; не се твърди, че `flutter analyze` или Android Release build са преминали. GitHub Actions трябва да потвърди тези проверки.
- За реално известяване на нова версия администраторът трябва да качи подписания APK на HTTPS адрес и да попълни `PCWork Mobile → Интеграции → Актуализации на мобилното приложение`.
- Ако GitHub Secrets за подписване не са настроени, Release build ще спре умишлено.
