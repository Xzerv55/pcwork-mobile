# iOS platform scaffold

The Flutter iOS Runner project and Xcode project are generated from the installed Flutter SDK in the iOS workflow (`flutter create --platforms=ios ...`). This checked-in scaffold keeps the iOS identity and CocoaPods setup visible in the source archive. Firebase iOS app configuration is supplied via the existing build-time Dart defines; APNs must be configured in the Firebase project for push delivery.

Bundle ID: `com.pcworkbg.pcwork_mobile`.
