# PCWork Mobile v73

## Подобрения
- Актуализиран е build номерът за правилно разпознаване на версията при проверка за актуализация.
- Добавено е краткосрочно кеширане на продуктовия каталог (45 секунди) и категориите (10 минути), за да се намалят повторните заявки при връщане в магазина. Кешът е изолиран по адрес на API сървъра.
- Премахнат е дублиран import в API слоя.
- Запазени са съществуващите екрани, интеграции и идентификатори на приложението.

APK не е включен в този source архив. Flutter анализът и реалният Android build трябва да се изпълнят в среда с Flutter SDK.
