# PCWork Mobile v76 source

Текуща мобилна версия: **0.76.0+76**. Базата е PCWork Mobile v75.

## Промени във v76
- Push известията маршрутизират към съответния екран; известията се премахват от активната история след отваряне на целевата услуга.
- Чатът изпраща съобщение с Enter; Shift+Enter запазва нов ред в административния уеб чат.
- Премахнато е плаващото чат балонче; достъпът до чата остава в основната навигация.
- В „Обяви“ действието „Вземи“ добавя продукта във вътрешната количка без външно пренасочване. В checkout е добавен избор на Econt, Speedy или Pigeon; наличните методи се филтрират по избрания куриер и се валидират повторно от WooCommerce при поръчка.
- GitHub Actions използва кешове за Pub и Gradle зависимости и избягва повторно разрешаване на пакетите при build.

APK не е включен. Компилацията се изпълнява през GitHub Actions.
