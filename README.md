# PCWork Mobile v74 source

Текуща мобилна версия: **0.74.0+74**. Базата е предоставеният PCWork Mobile v73 Fixed source.

## Основни промени във v74
- Компактен чат интерфейс и намалени празни пространства около полето за писане.
- При отваряне/повторно отваряне на чата се позиционира последното съобщение.
- Администраторски чат: служители с администраторски роли могат да виждат разговорите на клиентите и да отговарят през приложението.
- Чат push известията не показват изскачащ прозорец, докато приложението е отворено в таб „Чат“.
- При изход приложението заявява прекратяване на активните сървърни сесии; локалният изход остава работещ и без интернет.

## Проверки
Flutter SDK не е наличен в средата, затова `flutter analyze` и APK компилация не са изпълнени тук. Изходният код е предоставен за проверка и build в Flutter среда.
