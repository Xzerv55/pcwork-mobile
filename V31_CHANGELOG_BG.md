# PCWork Mobile v31

**Версия:** `0.31.0+31`  
**Платформи:** Android и iOS  
**Езици:** Български / English  
**API:** `https://pcwork-bg.com`

## Ново във v31 – управление на статуса на ремонтите
- Служителите и администраторите могат да променят статуса директно от детайлите на ремонта.
- Добавен е избор на всички поддържани етапи: приет, диагностика, очаква одобрение, в ремонт, готов, приключен и отменен.
- При промяна може да се добави бележка, която се изпраща към историята на ремонта.
- Записът минава през съществуващия защитен WordPress API `PATCH /repairs/{id}/status`; приложението не пази отделно локално копие на статуса.
- След успешно записване списъкът с ремонти се презарежда.
- Клиентските профили запазват само прегледа на статуса; бутонът за редакция е видим само за роли на служители/администратори.

## Допълнителни корекции
- Премахнати са двете lint забележки в `staff_management_screen.dart` и `api_service.dart`.
- Версията на приложението е повишена на `0.31.0+31`.
- Имената на GitHub Actions артефактите са обновени за v31.
- Запазена е корекцията във v30 за генериране на iOS asset catalog преди `flutter_launcher_icons` в Android workflow.

## Компилация
1. Качи съдържанието на тази папка в GitHub и замени старите файлове.
2. Отвори **Actions → PCWork Android APK**.
3. Провери стъпката `Analyze Dart code` да приключи успешно.
4. Изтегли `pcwork-android-v31-apks`.
5. За iOS стартирай **PCWork iOS unsigned build** и изтегли `pcwork-ios-v31-app-unsigned`.

**Бележка:** Flutter SDK не е наличен в средата, в която е подготвен архивът. Затова не твърдя, че `flutter analyze` или компилацията са изпълнени тук. Те трябва да се потвърдят от GitHub Actions.
