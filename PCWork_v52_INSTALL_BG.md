# PCWork Mobile v52 – инструкции за инсталиране

1. Качи новия WordPress плъгин `PCWork_WordPress_Plugin_v3.6.1.zip` от **Разширения → Добавяне на разширение → Качване на разширение**. Направи резервно копие и след това активирай/обнови плъгина.
2. В WordPress отвори **PCWork Mobile → Интеграции → Push известия**. Провери Firebase Project ID, Service Account JSON и тестовия FCM device token. Запази настройките. Не изпращай Service Account JSON или private key по чат и не ги добавяй в GitHub.
3. Качи съдържанието на този проект в частното GitHub хранилище. Реалният `android/app/google-services.json` трябва да остане в частното checkout/repository, както е изисквано от Android workflow; той не е включен в този ZIP.
4. Стартирай **Actions → PCWork Android APK → Run workflow**.
5. Изтегли APK артефакта от завършилия workflow. За повечето съвременни Android телефони инсталирай `app-arm64-v8a-release.apk`.
6. Провери началния екран: картите „Обади се“ и „TikTok“ трябва да показват само икона и име на услугата. Провери и долното меню на физически телефон.
7. Направи FCM тест от WordPress. Ако има грешка, изпрати само текста ѝ; никога не изпращай частния ключ.

Забележка: архивът съдържа изходния код. Не е извършена локална Flutter компилация в тази среда, затова APK трябва да се генерира от GitHub Actions.
